# Control de Accesos - Frontend
Frontend web del sistema de control de accesos desarrollado con Vite, JavaScript y Tailwind CSS.

## Novedades

### Módulo Fichadas
- Se agrega la vista de fichadas.
- Se incorporan filtros por empleado, fecha, tipo y método.
- Se agregan tarjetas de resumen diario.
- Se implementa tabla responsive.
- Se agregan estados de carga, error y sin resultados.
- Los datos mock quedan desacoplados de la UI para futura integración con la API.
- Se integra la vista al sidebar existente.
